# directFlow shell

Прототип интерфейса мобильной оболочки

## Ключевые особенности

- **Единое меню виджетов и ярлыков** — единственный способ добавить объект на стол.
- **Нет шторки** — уведомления и быстрые настройки живут виджетами на рабочем столе.
- **Жесты от краёв** — домой, недавние, назад; плюс свайп вверх для меню виджетов.
- **Единая сетка** — ярлыки и виджеты равноправны, перетаскиваются одинаково.
- **Зеркальный режим и режим трёх кнопок** — переключаются в панели слева от устройства.
